# 🧠 Knowledge 03: Reinforcement Learning & Self-Reflection Playbook

## 1. 강화학습(RL) 피드백 루프 개요

본 채널은 단순 업로드에 그치지 않고, 영상 배포 **24시간 후** 실제 유튜브 알고리즘 지표를 스크랩하여 **성공 요인과 실패 요인을 분리 학습**합니다.

```
[업로드 완료] ──▶ [upload_history.json 등록]
                       │
             (24시간 타이머 대기)
                       ▼
       [YouTube Data API 실시간 지표 수집]
       (조회수 Views, 좋아요 Likes, 댓글 Comments)
                       │
       ┌───────────────┴───────────────┐
       ▼                               ▼
[Views >= 5,000]               [Views < 5,000]
       │                               │
       ▼                               ▼
 [REWARD 획득]                 [PUNISHMENT 오답노트]
 • success_log.txt 저장         • fail_log.txt 저장
 • 시각적 훅 & 메뉴 패턴 공식화   • 이탈 원인 분석 및 개선안 도출
 • 후속 시리즈 즉시 확장          • 다음 편 프롬프트/사운드에 강제 반영
```

## 2. 평가 기준 및 임계값 (Thresholds)

| 등급 | 판정 | 조회수 (24h 기준) | 조치 사항 |
| :---: | :---: | :---: | :--- |
| **Tier A** | **REWARD (대성공)** | **10,000회 이상** | 해당 K-Food의 변형 메뉴(예: 까르보 불닭 ➔ 4가지 치즈 불닭)로 3부작 스핀오프 제작 |
| **Tier B** | **REWARD (성공)** | **5,000회 ~ 9,999회** | 비주얼 구도 및 ASMR 사운드 믹싱 볼륨 공식 유지 |
| **Tier C** | **PUNISHMENT (개선 필요)** | **1,000회 ~ 4,999회** | 초반 2초 비주얼 훅 보강(치즈 늘리기, 매운맛 불꽃 효과 등 도입) |
| **Tier D** | **PUNISHMENT (실패)** | **1,000회 미만** | 메뉴 선정 미스 또는 썸네일 어그로 결여 판정, 오답노트 작성 후 대체 메뉴로 전환 |

## 3. 오답노트 실제 누적 기록 사례

### [사례 1] 단순 커머스 제품 홍보 영상 실패 (`fail_log.txt`)
* **원인:** AI 비디오로 가습기 등 실물 제품 영상을 생성했을 때, 시청자가 0.5초 만에 광고임을 인식하고 즉시 스와이프 이탈.
* **학습 결론:** 실존 제품 판매 피벗 ➔ 전 세계인이 사랑하는 순수 힐링·도파민 엔터테인먼트인 **동물(고양이) 먹방 ASMR**로 전면 전환.

### [사례 2] 아나운서 음성 삽입에 따른 몰입도 저하 (`fail_log.txt`)
* **원인:** 먹방 영상에 영어 아나운서 음성이 들어가면서 씹는 소리(ASMR)의 청각적 쾌감이 반감됨.
* **학습 결론:** 사람 목소리 100% 제거 ➔ 영상 전 구간 고양이의 입 모양과 맞물리는 **초근접 연속 먹방 ASMR**로 완전 교체.
